# Fase 1 — Discovery (encerrada)

**Status:** feita em 16 set 2026. Não reabrir a menos que a visão mude (isso exigiria ADR).

## Objetivo

Traviar quem é o usuário, qual dor importa, e qual fatia do funil o produto cobre melhor do que o que já existe. **Sem código de produto.**

## Como começou

Esboço do autor: entrevistas cronometradas por áudio (RH + técnica Vibe Engineering sem live code + fit cultural), análise de CV e LinkedIn, indicação de plataformas e empresas, desafio só com enunciado, pontuação e feedback em tudo. Canal incerto (web e/ou mobile).

Método acordado: visão completa em esboço; **só a fase atual é aprofundada**.

## Pesquisa (desk, 16 set 2026)

### Funil real (pleno, remoto, inglês)

Aplicação → ATS/currículo → LinkedIn/busca passiva → recruiter screen (inglês falado, faixa salarial) → OA / take-home / live code (IA **mista**: umas empresas proíbem, outras esperam) → loop técnico (coding clássico **ou** AI-native / Vibe Engineering) → behavioral / fit (async, ownership) → offer.

O produto atua em cada etapa em fases diferentes (ver `product/modules.md`).
