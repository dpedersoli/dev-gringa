# Anti-escopo

O produto **não é** e não vai virar por acidente:

| Não é | Por quê | Vizinho que é isso |
| --- | --- | --- |
| Copilot invisível na entrevista real | Ético + posicionamento (D-016) | Final Round AI |
| Mentoria humana 1:1 | Custo, agenda, não é ferramenta pessoal | interviewing.io, mentoria VagaNaGringa |
| Gerador de CV que aplica por você | Queremos nota e gaps, não um PDF mágico na v1 | prepara.cv |
| Editor / juiz de live code | Diferencial é fala + vibe; live code é outro produto (D-012) | DevInterview.AI, LeetCode |
| Marketplace de vagas | Matching é indicação, não job board | LinkedIn, Remotive, Arc |
| SaaS com pagamento / waitlist | Ferramenta pessoal (D-001) | VagaNaGringa Pro |
| App mobile | Canal v1 = web (D-002) | — |
| Entrevista em português | Call real é inglês-US (D-005) | mocks bilingues da VagaNaGringa |
| Auth / contas / multi-tenant | Um usuário local (D-008) | — |
| Fit Score contra uma vaga colada na v1 | Score é de prontidão da pessoa, não de uma req | VagaNaGringa Fit Score |

Se uma ideia nova cair em qualquer linha desta tabela, recusar ou abrir ADR explícito para reverter.
